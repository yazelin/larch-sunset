# 即興 return take2（沈淮=gemini）

> 你推開門，門鈴響了。
**沈淮**　動作：（把門推上，轉身扣上門閂，鞋底在門口踩了兩下甩掉水。）
　台詞：（不說）
　心：（燈還開著，鑰匙放哪裡都一樣。）

> 你把信封放在吧檯上。
**沈淮**　動作：（把裝著鑰匙的信封輕輕推在吧檯上，指尖在牛皮紙邊緣停了一下。）
　台詞：（信封在這裡。妳母親的姓我寫在上面了。）
　心：（燈還是太亮了。）

> 你倒了半杯白開水喝。
**沈淮**　動作：沈淮拉開離自己最近的高腳椅坐下，把背挺直，兩三秒後才微微垮下來。
　台詞：（不說）
　心：水還是像水，一點味道都沒有。

> 你走到她平常站的位置。
**沈淮**　動作：走進吧檯裡面，右手順手摸了一下洗杯槽旁邊的抹布。
　台詞：這幾天沒開，裡面都有點乾了。
　心：我還是習慣站在這邊看妳。

> 吧檯下的小抽屜裡，是她的小筆記本。你從沒翻過。
**沈淮**　動作：右手拉開吧檯下方的小抽屜，指尖碰到筆記本封皮的硬紙，把它拿出來放到檯面上。
　台詞：這本我以前都沒看過。
　心：今天看完，明天就交鑰匙了。
