# 即興 return take2（沈淮=gemini）

> 你推開門，門鈴響了。
**沈淮**　動作：你推開門把，門鈴叮噹響了一聲，手在門把上記得沒鬆開。
　台詞：我回來了。今天比較晚。
　心：這門的油該加了，上次就想講。

> 你把信封放在吧檯上。
**沈淮**　動作：你把信封推到吧檯正中央，指尖在牛皮紙邊緣多按了一下才拿開。
　台詞：鑰匙在這裡。明天早上她母親會來拿。
　心：這七天沒吃完一碗飯，舌頭真的壞了。

> 你倒了半杯白開水喝。
**沈淮**　動作：你端起玻璃杯，水面晃了一下，你沒看水，盯著杯底那一圈水痕。
　台詞：（不說）
　心：水還是沒有味道。

> 你走到她平常站的位置。
**沈淮**　動作：我跨進吧檯後面，腳鞋底踩在防滑墊上，轉過身面向空著的高腳椅。
　台詞：這位置真的比外面低一點。妳以前怎麼站整晚的？
　心：這裡還全是妳的味道。

> 吧檯下的小抽屜裡，是她的小筆記本。你從沒翻過。
**沈淮**　動作：（你拉開吧檯下方的小抽屜，指尖碰到筆記本的書背停住。）
　台詞：（不說）
　心：（本來以為只是放帳本的地方，怎麼會是這個。）
