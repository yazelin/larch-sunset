# 即興 return take1（沈淮=argon）

> 你推開門，門鈴響了。
**沈淮**　動作：反手把門帶上，走到牆邊只按亮吧檯上方那盞燈。
　台詞：外面雨很大，我今晚走正門進來。樓上都收好了，下來跟妳坐一下。
　心：這七天都走後面樓梯避開這裡，現在聽見門鈴響，還是覺得妳人就在吧檯裡面。

> 你把信封放在吧檯上。
**沈淮**　動作：從口袋拿出沒封口的信封平放在吧檯上，手掌在信封旁邊停了一下才收回來。
　台詞：店裡的帳我都對完了，鑰匙裝在裡面留給妳媽。明天早上十點房東會過來點交。
　心：信封上的字寫得有點歪，妳看到一定又要念我。

> 你倒了半杯白開水喝。
**沈淮**　動作：拿起水壺倒了半杯白開水，低頭喝了兩口，把水杯放回面前。
　台詞：這幾天吃飯都沒味道，喝水也是一樣。醫生看過說舌頭沒問題，叫我再回診我也沒約。
　心：人家說頭七妳會回家，我今晚就坐在這裡等妳回來。　〔沒過：說破味覺〕

> 你走到她平常站的位置。
**沈淮**　動作：繞進吧檯走到她平常站的地方停下來，低頭把鬆開的襯衫袖口重新往上捲好。
　台詞：我自己捲袖子還是很容易掉，妳看到又要唸我手笨了。今天有一點累，借妳的位置站一下。
　心：人家說今晚妳會回來，我就站在這裡等妳到兩點十七分。

> 吧檯下的小抽屜裡，是她的小筆記本。你從沒翻過。
**沈淮**　動作：拉開吧檯下的小抽屜，把裡面的小筆記本拿出來直接疊到信封上，再把抽屜推回去。
　台詞：這本筆記本我也拿出來放著，不然明天交屋就忘在抽屜裡了。妳以前寫的時候都用手遮住，我剛剛一樣沒翻開。
　心：本來想等妳親口教我裡面的酒譜，現在我自己看也沒用了。
