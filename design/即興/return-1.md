# 即興 return take1（沈淮=argon）

> 你推開門，門鈴響了。
**沈淮**　動作：反手把店門帶上，伸手按亮牆邊那顆只連著吧檯上方吊燈的開關。
　台詞：過十二點了，外頭雨還沒停。我進來坐一下。
　心：這七天我都走後面的樓梯，不知道妳今晚回來了沒有。

> 你把信封放在吧檯上。
**沈淮**　動作：從口袋拿出那只寫著她母親姓氏的沒封口信封擺上吧檯，手指在木頭檯面上停了一下才收回來。
　台詞：店裡的帳跟廠商尾款我都結清了。鑰匙先放這，明天早上十點房東跟妳媽會過來拿。
　心：醫院那邊我沒約回診，反正過了今晚也用不著了。

> 你倒了半杯白開水喝。
**沈淮**　動作：拿玻璃杯去水槽接了半杯白開水，仰頭喝了一大口，自己捲鬆的襯衫袖口順著手腕滑下來。
　台詞：樓上今天下午收乾淨，搬那幾箱東西還滿累的。這幾天吃飯沒什麼味道，喝白開水比較乾脆。
　心：醫生說舌頭沒問題要我下禮拜回診，我離開醫院前沒去櫃檯掛號。

> 你走到她平常站的位置。
**沈淮**　動作：繞進吧檯內側的正中央站定，拿起瀝水墊上的長柄吧匙，大拇指輕靠著匙柄轉了半圈又放回原位。
　台詞：以前站這格老被妳嫌擋路，今天借我站一下。吧匙我現在拿得穩了，妳別再笑我只會洗杯子。
　心：等一下坐到兩點十七分我就把燈關了，醫院那邊的回診也不用去約了。

> 吧檯下的小抽屜裡，是她的小筆記本。你從沒翻過。
**沈淮**　動作：拉開吧檯下方的小抽屜，取出裡頭的小筆記本捧在掌心，低頭掀開封面。
　台詞：抽屜還留著這本，裡頭是記酒譜還是記我打破幾個杯子？我打開看一下喔。
　心：好幾次坐到兩點十七分等妳收完店，看妳低頭寫這本，我都沒敢問妳在寫什麼。
