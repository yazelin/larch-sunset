# 《晚霞是舌尖最後的刺痛》重寫設計（2026-10-17 作者拍板方向）

## 為什麼要重寫

作者 2026-10-17：「故事上我期待的是更完整、更充滿悲劇的文學作品，讓人看了能忘不了安雅，就像沈淮一樣。」「我希望玩家能理解安雅身上發生的事，以及做出喝下晚霞的意義。能不聽安雅的話，就是決定要喝下。」

現況的問題：玩家只在結尾那三段回憶見得到活著的安雅，其他時候她只是便條、病歷單和遺言；她瞞病的三年沒有任何一場戲；抉擇只是「喝／倒」，喝下去的意義沒有被建立。

## 目標

- 玩家玩完能說出安雅身上發生了什麼：初遇後幾個月確診味覺中樞會壞死，瞞著沈淮三年，教他調酒、靠他的舌頭，最後自己調出晚霞，在 02:17 喝下。
- 玩家走到抉擇時，喝下晚霞有清楚的意義：她用盡一切要他活，他的愛是跟她走；他違背她最後的請求，替她回答她到最後都不知道答案的「甜嗎」，讓她不是一個人走。不聽她的話＝選擇喝。
- 安雅是活生生的人：溫暖、愛笑、在吧檯後面說了算、會主動伸手、什麼都自己扛（個性以 design/回憶篇.md 開頭那段為準）。
- 文學性與悲劇色彩：伏筆在前、真相在後，同一句話第二次出現時意思變了。

## 不做的事 / 會讓這次失敗的事

- 不做成解謎遊戲加一段感人結尾。回憶要穿插在解謎中間，每找到一樣材料就回到一段過去。
- 不把她寫成嘴硬型，也不讓她一見面就心動（作者 2026-10-16 已糾正過）。
- 旁白不解釋內心；讓人在場、讓人說話（見記憶 feedback_vn_dialogue_over_narration）。
- 不用更聲、燈芯這類時間填空；時間靠事情推。
- 喝下是故事內的殉情選擇。介面上不加「真結局」「好結局」這類標籤或成就字眼，留給故事本身去說服玩家。

## 調性：成人、浪漫、克制（作者 2026-10-17）

作者：「你看《起跑總在開始前》的故事也是類似這種小短篇，愛情也讓人喜歡。這篇晚霞我想要更成人一點、浪漫。」

從《起跑》原文（~/larch-start-line/canon/原文.md）學的是寫法，不是情節：
- **親密寫在小動作裡。** 求婚沒有戒指、沒有尖叫，只有「好啊」和下巴抵在肩窩。晚霞的親密也這樣寫：她穿他的襯衫、他替她把落下的髮絲挽到耳後、打烊後兩人在空店裡跳一支沒有音樂的舞。
- **真相回頭改寫前面。** 《起跑》的零錢是她算好的；晚霞的「甜」是她說謊。玩家第二次聽到同一句話，意思變了。
- **天氣與身體當隱喻。** 《起跑》用暴雨前的氣壓；晚霞用雨、日出、晚霞和舌尖的刺痛。
- **開頭與結尾各有一段沈淮的獨白**，像《起跑》開頭「所謂的起跑」與結尾「世人總在等那聲槍響」，講「味道」和「最後一口」。

「成人」的範圍（Claude 的提議，作者可改）：
- 兩人是同居的成年戀人，臥室那張地圖就是他們樓上的房間。
- 可以有吻、相擁入睡、清晨醒來、隔天早上穿著他襯衫的她；床戲用轉場帶過，不寫露骨的身體描寫（Larch 是公開市集）。
- 情感上成人：她選擇不說、他假裝沒發現的時刻，兩人都懂卻沒有說破。
- 回憶一的初遇保留三拍，但把「嗆到、笑到眼角濕」這類可愛的段落收斂，張力靠眼神、距離和沉默。

這會改到的場面：
- 回憶二結尾：手沒有放開之後，隔著吧檯第一次吻。
- 回憶三的凌晨場面改成：他半夜醒來，床的另一邊是空的，還留著她的體溫；下樓看見她穿著他的襯衫，一個人坐在吧檯前，面前一整排只少一口的杯子。
- 回憶四頂樓：看完晚霞，兩人在風裡慢慢跳舞，她說「好甜」。

## 她為什麼留下這一切（作者 2026-10-17 拍板：整合版）

**她用盡一切要他活下去，但做不到用一個謊結束這段感情。** 她要是什麼都毀掉，他會一輩子以為她是突然走的；那是瞞了三年之後最後一個、永遠拆不穿的謊。兩件事都放不下，所以她**只藏、不毀**：

| 她藏了什麼 | 怎麼藏 | 對應現有的謎 |
|---|---|---|
| 配方 | 最後一晚燒了風味筆記，燒到一半停手 | 吧檯風味筆記三題：他從殘頁補上燒掉的三格 |
| 黃銅匙 | 收起來，不讓他拿去調 | 吧檯取匙 |
| 番紅花糖漿、心型吊墜鑰匙 | 藏進儲藏間受潮咬死的抽屜（鑰匙是她平時貼身戴的） | 儲藏間撬抽屜 |
| 病歷單與有毒的粉紅胡椒（纏著「這罐有毒」的字條） | 鎖進木盒，鎖碼 02:17，刻著「如果遺忘了，就永遠別打開它」：如果你已經往前走了，就別打開；如果你還記得，真相在這裡 | 臥室木盒 |

- **便條**（序幕，壓在空杯下）只寫要他好好活、把店顧好，完全不提酒。方向：『沈淮，店交給你了。不要找我留下的東西。』他偏偏去找。
- **遺言**壓在她吧檯的工作位上：她料到他會一路找到這裡、站到她的位置調那杯酒。他把杯子放下時看見。遺言做三件事：承認她料到了（「我就知道你會調。」）、說實話（她騙了他三年、她先喝了這一杯）、求他（「不要嚐它，替我倒掉。」）。毒在胡椒裡這件事字條已經說過，遺言可以再提一次。
- **他為什麼還是喝**：他知道了全部、也聽見她的請求。她已經不在了，他只想跟她走；她到最後都不知道那杯對不對，他想替她嚐一次，告訴她「甜的」。這個問題是他自己想回答的，她從沒要求。

**兩杯酒的名字（作者 2026-10-17）**：初遇那杯叫〈破曉〉（甜白酒、番紅花糖漿、杯口磨幾粒一般的粉紅胡椒，無毒；她還嚐得到），最後那杯叫〈晚霞〉（同一套配方，胡椒換成木盒裡有毒的那罐；她嚐不到，憑記憶調）。從日出走到日落，就是他們這三年；遺言「金黃像日出，粉紅像晚霞」講的是同一杯裡兩個時刻疊在一起。吧檯謎題原有「初遇像破曉」，回憶一她問「像不像天快亮的時候？」，都對上〈破曉〉。

**毒在粉紅胡椒裡**：其他材料（甜白酒、番紅花糖漿）都無毒。片名「舌尖最後的刺痛」就是這罐胡椒。倒掉結局後日談裡「沒有毒的晚霞」＝換成一般的粉紅胡椒。

**她一定讓他知道那有毒（作者 2026-10-17）。** 她可以藏，但不能讓他在不知情時碰到毒。所以木盒裡那罐胡椒用她的字條纏著：「這罐有毒。我用的就是它。不要碰。」沈淮在臥室拿到胡椒的那一刻就知道。從這裡開始，他是明知有毒還走回吧檯。

## 沈淮為什麼一路調下去

1. 序幕：吧檯上的空杯，杯底還留著一點金黃和粉紅。這是她最後喝的東西，他想知道那是什麼。
2. 燒到一半的風味筆記：他認出是初遇那晚的味道。她最後做的事是調這杯，他想嚐她最後嚐的。
3. 匙、糖漿：回憶一段一段回來，他越調越靠近她。
4. 臥室：病歷讓他知道她病了、瞞了三年；胡椒上的字條讓他知道毒在哪裡、她就是這樣走的。他還是把胡椒帶走了。玩家在這裡就感覺得到他想做什麼。
5. 吧檯：他站到她的工作位把酒調好，放下杯子，看見她壓在那裡的遺言。她料到了：「我就知道你會調。」她再求他一次，倒掉。
6. 抉擇：他知道一切、也聽見她兩次的請求（字條、遺言），才決定。

## 時間點：頭七（Claude 的提議，作者同意整份方向）

遊戲開始在她過世第七天的深夜，沈淮第一次回到吧檯。他以為她是突然走的（心臟），其他什麼都不知道。序幕那只壓著便條的空高腳杯，就是她最後喝晚霞的杯子：玩家一開場就看到，到最後才懂。她的靈魂在頭七出現，對上台灣的習俗。

序幕要改的字：從「吧檯上的燈還亮著」改成頭七那晚他推門回來，店已經停業七天。

## 遺言（card_confession，改寫）

照「她為什麼留下這一切」與「沈淮為什麼一路調下去」：她料到他會調；說實話（她先喝了、她瞞了三年）；再求他倒掉。不寫「想要有人替我嚐」。可以讓她承認她料到他會找到這裡。語氣要像她本人，不寫成說明書。

## 作者偏愛的結局：〈共赴晚霞〉（作者 2026-10-17）

作者：「共赴晚霞就是我喜歡的結局。」全劇的鋪陳都朝這一刻走：回憶、伏筆、遺言要讓玩家在抉擇時自己想喝。〈共赴晚霞〉是最用力做的一段：卡片最多、CG 最精、配樂是主題曲的完整版、最後一段沈淮獨白收全劇。〈冷卻的餘溫〉保留，做得完整但短。

## 安雅的心境（寫她的台詞時以此為準；Claude 的解讀，作者 2026-10-17 讀過）

1. **初遇：被嚐懂。** 那晚她還嚐得到。他說「好辣……可是好甜」說中了她最喜歡的那杯。對調酒師來說，有人嚐懂她的酒，就是被懂。所以她記得 02:17。
2. **確診：決定不說。** 她怕他留下來是因為同情；她想被愛，不想被照顧。
3. **教他調酒：兩個理由。** 把自己最會的給他（愛）；「以後我調不動了，你要替我調」（準備一條替她嚐的舌頭，也替他準備一門沒有她也活得下去的手藝）。兩個理由同時成立。
4. **「甜嗎」：靠他記住世界。** 她已經嚐不出來，靠他的回答記住每杯該是什麼味道。頂樓的「好甜」是謊：不想讓他看見她在失去，也想留給他一個完整的晚霞。
5. **研發晚霞：自己選怎麼結束。** 痛一天比一天清楚。用初遇的配方，因為她要最後一口是那天晚上；但她嚐不到，只能憑記憶調。一整排只少一口的杯子，是她一次又一次試著回到那個晚上。
6. **02:17 喝下。** 在相遇的那一刻結束，把故事收成一個圓。喝下時她還是不知道那杯對不對。
7. **只藏、不毀。** 她要他活，所以藏；她做不到用一個謊結束這段感情，所以不毀。木盒那句刻字是在求他忘記，可是她知道他不會忘。
8. **她最深的那一句。** 她最怕的，是他跟著她走。

## 抉擇與結局

作者 2026-10-17：「CG 必需美，否則沒有人看得下去。因為是文學作品，背後的理由和美感必需拉滿。」所以每張 CG 都要先寫清楚兩件事，才能送去產：

- **美感**：光從哪裡來、主色是什麼、鏡頭距離與角度、畫面裡留白在哪裡。沒有寫到的地方模型會自己發揮，所以要寫進設計。

全劇的視覺母題（Claude 的提議）：
- **杯子**：同一只碟形香檳杯貫穿全劇：初遇她推給他、最後她自己喝下、序幕壓著便條、結局他喝下或倒掉。
- **光的顏色**：回憶是暖金（日出、吊燈），真相之後轉成粉紅與紫（晚霞），頭七的現在是冷藍。結局〈共赴〉是全劇唯一一張冷藍被金粉色吞沒的畫面，〈餘溫〉則整張冷藍、只剩水槽裡一點粉紅。
