# 第五輪：全劇精修計劃（2026-11-12）

作者問第四版「還有什麼對話 AI 味之類的問題」，並交代「把完整重寫精進計劃做好後執行」。這一輪由 Claude 從頭讀完 47 張卡後自己改，不派工。

## 讀完後的判斷

第四版的對白已經是台灣口語，鬥嘴、熟客、四個轉折都在，骨架不動。剩下的機械感集中在五處：

1. **同一批資訊講兩遍**：`return`、`return_2` 與 `farewell_3` 都是頭七當晚，房東點交、鑰匙給她母親、吃兩口、明天住哪，各講了一次。
2. **話講得含糊，讀者要猜**：「明天就讓他打給阿姨吧」「後面那瓶／妳右手那瓶」「樓上也收好了，她不用再上去整理」「兩碗好了，你一定又全吃掉」。
3. **跨卡對不上**：`flash_1` 心聲「連檸檬的酸都沒了」，同一段時間的筆記寫的是「淡」；沈淮對安雅說話時「妳媽」「阿姨」混用；`weeks_2` 椅子挪出去之後膝蓋還碰著。
4. **旁白像舞台指示**：47 張卡有 46 張第一句是「時間，地點，誰把什麼放到哪裡」同一個句型；同一夜連續幾張卡每張重報一次「頭七深夜，吧檯後」；`winter_3` 十二句旁白全是「他……」「她……」交替。
5. **對白的小毛病**：指揮位置的梗（左手邊、右邊）用太多次；幾句簡報腔（`quit_1` 生活費與店裡收入、`weeks_2` 一口氣報完病史）；讀稿人共識抓到、原句還在稿裡的搭配不當。

## 做法

1. 寫 `審稿/pattern_scan.py`，把上面第 1、4、5 項量成數字，改前改後各跑一次。
2. 逐卡改。沒問題的句子不動；準則 14（每張卡開頭交代時間地點）照守，只換句型；準則 8 的物件寫法不動；作者留下的句子（「你調的，都好甜」「妳讓我在這裡當傻子兩年？」「記得吃飯」「我這裡不缺洗杯子的」）不動。改一句之前先搜別張卡有沒有回提。
3. 每張改過的卡過閘門（`runner.py gate … --by claude`）。不通過的卡看紀錄再改一次；第二次還不過，文字口味的改動換回舊句，只留跨卡邏輯的修正（閘門逐卡比，看不到跨卡的重複與矛盾，這類修正不靠閘門裁決）。
4. 全劇從頭再讀一遍查跨卡邏輯，跑掃描、speak-tw，用 `runner.py ship` 提交，不推送。
5. 作者 11-12 晚改口：不逐卡看，只在 Larch 預覽最終版。確認頁取消；改成整部通讀查跨卡邏輯（多位讀稿人各讀一遍全劇），過了就直接進分鏡、CG、配樂、組裝。之後的決定記在 `design/重製.md`「代決紀錄」。
